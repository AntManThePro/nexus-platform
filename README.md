# NEXUS — Algorithmic Creativity Platform v1.0

Six vanilla tools in one place: ANSI art, a curator, an evolutionary playground, QuantumShift, Terminal Poster, and ANSI Lab. Algorithms should be beautiful — see it running, change the parameters, learn by doing.

**Live:** https://nexus-platform-doublea.netlify.app/

## How to use

1. Open the live site and pick a tool from the main page.
2. Play with the parameters live — everything runs in your browser.
3. Curator and Evolutionary also have React versions kept in `react/` — the vanilla pages in `ecosystem/` are the canonical ones.

## Notes

- Vanilla HTML/CSS/JS, zero dependencies on the main tools. Works offline once loaded.
- Philosophy: ship fast, iterate in public, let the community lead. Perfection kills progress.
