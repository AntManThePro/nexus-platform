## Current NEXUS Products

### 1. NEXUS Evolutionary Algorithm Visualizer
**Live genetic algorithm with real-time population evolution**

- Watch organisms evolve toward fitness targets
- Interactive population size and mutation rate controls
- Three target modes: center, spiral, dynamic following
- Canvas-based real-time rendering with velocity trails
- Fitness statistics dashboard (generation, avg fitness, best fitness)
- No external dependencies—pure vanilla JavaScript

**Interview Value:** Demonstrates algorithmic thinking, fitness modeling, and selection mechanisms. Perfect for explaining emergent complexity from simple rules.

**Use Cases:**
- Portfolio conversation starter
- Educational tool for evolution concepts
- Live demo during technical interviews
- Teaching genetic algorithms fundamentals

- Copy-to-clipboard and download-as-text functionality
- Mobile-responsive design (desktop and mobile)
- Ant mascot branding (🐜)

**Interview Value:** Positions you as the person who legitimized terminal aesthetics in modern web development. Shows design thinking + code together.

**Positioning:** The definitive ANSI art platform. Not just a tool—an entire creative community.

## Design System: NEXUS Aesthetic

### Color Palette
```
Primary:  Neon Green   #00ff87  (Life, activation, success)
Accent 1: Cyan         #60efff  (Information, tech, cool)
Accent 2: Hot Pink     #ff0080  (Action, warning, intensity)
Accent 3: Yellow       #ffcc00  (Highlights, joy, energy)

Background: Deep navy to black gradient (0a0e27 → 000000)
Text: Neon green on black for maximum legibility
```

### Typography
- **Display:** Courier New, monospace (futuristic, terminal-authentic)
- **Body:** Same (consistency, authenticity)
- **Font Weight:** Bold for headers, regular for body

### Motion
- **Entrance:** Slide down + fade in (0.6–0.8s)
- **Hover:** Scale 1.1 + glow effect (0.2–0.3s)
- **Active:** Scale 0.95 (tactile feedback)
- **Animations:** Floating, pulsing, gradient shifts

### Components
- **Buttons:** Bordered, no fill, glow on hover
- **Inputs:** Black background, colored borders, bright caret
- **Ranges:** Gradient track with glowing thumb
- **Cards:** Transparent background, colored borders, shadow effects
