**Create beautiful ASCII art with a professional editor**

- Persistent gallery (saves to browser storage)

**Animate ASCII art and generate procedural patterns**
- Keyframe timeline editor (up to 50 frames)

- Real-time playback with adjustable speed
- Export as: ANSI sequences, JSON keyframes, plain text
- Interview talk: "I built animation and generation into one tool"

**Live genetic algorithm with population evolution**
- Watch organisms evolve toward fitness targets in real-time
- Interactive controls: Population size, Mutation rate
- 3 target modes: Center, Spiral, Following
- Statistics dashboard: Generation, Avg Fitness, Best Fitness
- Interview talk: "Here's how emergent complexity works from simple rules"

**ANSI terminal poster generation with live rendering**
- Real-time customization (font size, complexity, color scheme)
